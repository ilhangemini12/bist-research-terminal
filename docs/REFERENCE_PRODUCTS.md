# Reference product notes

This file records UX/feature inspiration only. It does **not** grant ingestion rights and does not turn a public UI into a permitted automated data source.

| Product | Design ideas retained | Ingestion policy |
|---|---|---|
| QueenStocks/QPS | Fundamental + technical rules, custom formulas, saved strategies, strategy comparison, backtesting | Reference only; paid product is not used as a data source |
| ForInvest | Personalized lists, live-data UX, research/news aggregation, technical analysis surface | Candidate only; automated ingestion disabled until terms are explicitly acceptable |
| Piapiri | Personalized home/tabs, watchlists, research reports and model portfolios | Candidate only; account/login boundary is respected |
| MatriksIQ | Dense terminal workflows, formula/strategy tools, technical depth | Paid source skipped |
| iDeal | Customizable terminal, scanner/system tester concepts | Paid source skipped |
| ZBorsa | Local broker UX, research/technical/KAP integration | Login-required; no automated ingestion |
| TradeAll TR | Depth/chart/news/research workflow | Login-required; no automated ingestion |
| Gedik Trader | Watchlists, technical detail, news and trading workflow | Login-required; no automated ingestion |

The terminal intentionally separates **product inspiration** from **data-source authorization**.
